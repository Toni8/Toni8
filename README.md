**End-to-end marketing analytics and business intelligence solution for a South African retail business.**

## 🌍 Urban Air Quality Health Risk Predictor
**End-to-end machine learning platform for predicting public health risks from air pollution.**

Designed and developed a complete machine learning pipeline that ingests environmental data, engineers predictive features, trains an XGBoost model, and delivers health risk predictions through an interactive Streamlit application.

**Highlights**

- 🌎 Environmental Data Pipeline
- 🤖 Machine Learning (XGBoost)
- ⚙️ Automated Data Engineering
- 📊 Interactive Streamlit Dashboard
- 🔍 Feature Engineering & EDA
- 📈 Public Health Risk Prediction

**Tech Stack**

`Python` • `MySQL` • `XGBoost` • `Streamlit` • `Scikit-Learn`
